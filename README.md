# CCCS 610, Assignment 3: code, results and figures

Supporting material for Sebastián Vielmas's report "Assignment 3: Synchrony, Epidemics and Resilient Networks" (McGill University, School of Continuing Studies, CCCS 610 Digital Thinking for Data Analysis, sessions 9 to 11). The report cites files here by path.

| Folder | Holds |
|---|---|
| `code/` | One Python script per session: `m09_sync.py` (fireflies), `m10_epidemic.py` (waning immunity), `m11_resist.py` (vertex removal), and `legible.py`, a helper the scripts use to check figure text size. Each states how to run it in its docstring. |
| `results/` | The JSON files behind every number and table in the report, one per session. Each script writes its file again, byte for byte, when it is run with the same seeds. |
| `figures/` | The nine figures of the report. |

There is no `data/` folder: every input is generated by the scripts from the seeds listed in the report, and no external data set is used.

The scripts need Python 3.12, numpy, networkx and matplotlib. They do not need scipy.
